# Veygo Landing Page

Landing page responsive basada en el diseño entregado.

## Archivos
- index.html
- styles.css
- script.js

## Cómo ejecutarlo
Abre `index.html` directamente en el navegador.

Las fotografías utilizan URLs de Unsplash, por lo que se necesita conexión a internet para mostrarlas.

## Mejora incorporada
Se eliminan los CTA repetidos del Hero y se agrega una sección compacta:
- Quiero alquilar un vehículo → arrendatario
- Quiero publicar mi vehículo → arrendador
